# قارئ الكتب — نسخة أولية

تطبيق Android تجريبي باسم «قارئ الكتب» مع اسم أحمد الشاذلي في الواجهة.

## الموجود في النموذج
- واجهة عربية RTL متجاوبة مبدئيًا للهاتف والتابلت.
- شاشة رئيسية ومكتبة تجريبية وقارئ صفحات.
- اختيار ألوان الورق: أبيض، عاجي، ورقي قديم، أخضر فاتح، ليلي.
- خيارات شكل التقليب في الإعدادات (واجهة اختيار فقط في هذه النسخة).
- شريط لضبط سطوع نافذة التطبيق وحجم الخط.
- لا يحتاج اتصالًا بالإنترنت لتشغيل المحتوى التجريبي.

## حدود هذه النسخة
هذه نسخة بداية برمجية، وليست إصدارًا نهائيًا. تأثيرات التقليب الأربعة معروضة كاختيارات إعدادات، لكن لم يتم بعد تنفيذ محاكاة الانحناء ثلاثي الأبعاد. الكتب الموجودة نصوص تجريبية وليست كتبًا إسلامية كاملة. لم يتم بناء APK أو اختباره على جهاز حقيقي في بيئة الإنشاء هذه.

## طريقة الفتح والبناء
1. فك ضغط الملف.
2. افتح مجلد `QariAlKutub` في Android Studio.
3. انتظر مزامنة Gradle.
4. شغّل التطبيق على محاكي أو هاتف أندرويد.
5. لإنشاء APK تجريبي: Build > Build Bundle(s) / APK(s) > Build APK(s).
